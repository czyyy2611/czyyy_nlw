思考题

  1. 阅读下面给出的 DM 的输入示例中（示例 DM 容量为 4KB，即 32bit × 1024字），根据你的理解回答，这个 addr 信号又是从哪里来的？地址信号 addr 位数为什么是 [11:2] 而不是 [9:0] ？
    addr 信号是ALU的计算结果；
    实际实用是按字寻址，addr 必然是4的倍数，后两位必然是0，所以只需要[11:2]就行了
  2. 思考上述两种控制器设计的译码方式，给出代码示例，并尝试对比各方式的优劣。 使用三目运算符来译码，优势：简洁，易于维护
    劣势：不够直观
  3. 在相应的部件中，复位信号的设计都是同步复位，这与 P3 中的设计要求不同。请对比同步复位与异步复位这两种方式的 reset 信号与 clk 信号优先级的关系。
    同步复位：clk > reset
    异步复位: clk < reset
  4. C 语言是一种弱类型程序设计语言。C 语言中不对计算结果溢出进行处理，这意味着 C 语言要求程序员必须很清楚计算结果是否会导致溢出。因此，如果仅仅支持 C 语言，MIPS 指令的所有计算指令均可以忽略溢出。 请说明为什么在忽略溢出的前提下，addi 与 addiu 是等价的，add 与 addu 是等价的。提示：阅读《MIPS32® Architecture For Programmers Volume II: The MIPS32® Instruction Set》中相关指令的 Operation 部分。 在忽略溢出的情况下，代码可以直接改写成： 和addu是等价的

添加各种指令流程

流程

  1. 判断是那种类型的指令
  2. 在Controller中添加指令识别
  3. 修改控制信号
控制信号 选择意义 指令取值
NPC_Sel 2'b00 : PC+4
2'b01 : J型跳转
2'b10 : 寄存器跳转
2'b11 : Branch分支		 • 正常顺序指令：默认 2'b00
• j, jal : 2'b01
• jr, jalr : 2'b10
• 所有 B 类（beq, bne 等）：2'b11
RegWrite 1 : 写寄存器
0 : 不写寄存器		 • 计算指令（R/I型）、Load指令、Link指令为 1
• Store 类、普通 Branch、纯跳转指令严格为 0
• 条件写入（如 bgezal）：zero ? 1 : 0
RegDst 1 : 写 rd
0 : 写 rt		 • R 型计算指令（add, slt）、jalr 为 1
• I 型计算指令（addi）、Load 指令为 0
Regra 1 : 强制写 $31 ($ra)
0 : 正常选 rd/rt		 • 只有带固定返回地址的指令（jal, bgezal）为 1
• jalr 写入的是 rd，因此 Regra 必须为 0！
PCtoReg 1 : 写回数据选 PC+4
0 : 选其他数据		 • 所有带链接功能的指令（jal, jalr, bgezal）为 1
• 其余指令为 0
MemtoReg 1 : 写回数据选内存读出值
0 : 选 ALU 运算值		 • 所有 Load 类指令（lw, lb, lh）为 1
• 其余指令为 0
ALUsrc 1 : 操作数 B 选立即数 ext32
0 : 操作数 B 选寄存器 RD2		 • I 型计算指令、Load、Store 指令为 1
• R 型计算指令、Branch 指令为 0
EXTop 1 : 符号扩展
0 : 零扩展		 • 算术计算（addi, slti）、Load/Store 偏移为 1
• 逻辑计算（andi, xori）为 0
MemWrite 1 : 写内存
0 : 不写内存		 • 只有 Store 类指令（sw, sb, sh）为 1，其余全为 0
storeSel 2'b00 : sw (整字)
2'b01 : sh (半字)
2'b10 : sb (单字节)		 • sw 为 2'b00
• sh 为 2'b01
• sb 为 2'b10
• 非 Store 指令填 2'b00
loadSel 2'b00 : lw (整字)
2'b01 : lh (有符号半字)
2'b10 : lb (有符号字节)		 • lw 为 2'b00
• lh 为 2'b01
• lb 为 2'b10
• 无符号读（lhu/lbu）在 DM 中根据扩展增加对应编码
  1. 修改数据通路
    需要ALU新算子 -> 改ALU
    需要新比较条件 -> 改CMP
    需要特殊读写宽度 -> 改DM

B型指令

  1. 语义：根据寄存器比较结果决定是否相对跳转（PC = PC + 4 + offset）。
  2. Controller 配置：
    • NPC_Sel = 2’b11
    • 普通 Branch（beq, bne, blez, bgtz）：RegWrite = 0
    • 带链接 Branch（bgezal, bltzal）：
      • RegWrite = zero ? 1 : 0（满足跳转才写）
      • Regra = 1（写 $31），PCtoReg = 1（写 PC+4）
  3. 数据通路修改：
    • 修改 CMP.v：增加分支判定（zero = (inputA != inputB) 等）

J型指令

  1. 语义：无条件跳转或寄存器跳转，按需保存返回地址。
  2. 各指令对号入座：
    • j：NPC_Sel = 2’b01，RegWrite = 0
    • jal：NPC_Sel = 2’b01，RegWrite = 1，Regra = 1（写 $31），PCtoReg = 1（写 PC+4）
    • jr：NPC_Sel = 2’b10（跳转目标来自 RD1），RegWrite = 0
    • jalr：NPC_Sel = 2’b10，RegWrite = 1，RegDst = 1，Regra = 0，PCtoReg = 1
  3. 数据通路修改：无，仅 Controller 改动即可。

计算型指令（R型）

  1. 语义：两个寄存器操作数运算，结果写入目标寄存器 rd。
  2. Controller 配置：
    • NPC_Sel = 2’b00
    • RegWrite = 1，RegDst = 1（写 rd）
    • ALUsrc = 0（选 RD2）
    • type：分配新的 ALU 操作码
  3. 数据通路修改（ALU.v）

计算型指令（I型）

  1. 语义：寄存器与立即数运算，结果写入目标寄存器 rt。
  2. Controller 配置：
    • NPC_Sel = 2’b00
    • RegWrite = 1，RegDst = 0（写 rt）
    • ALUsrc = 1（选 ext32）
    • EXTop：
      • 算术类（addi, slti）：EXTop = 1（符号扩展）
      • 逻辑类（andi, xori）：EXTop = 0（零扩展）
    • type：分配或复用 ALU 操作码
  3. 数据通路修改（ALU.v）

访存型指令（Load/Store）

  1. 共通点：ALUsrc = 1，EXTop = 1，type = （？）。
  2. Load 类（读内存）：
    • RegWrite = 1，RegDst = 0（写 rt），MemtoReg = 1（选内存读出），MemWrite = 0
    • loadSel：00 为 lw，01 为 lh，10 为 lb。
    • 无符号加载（lbu, lhu）：在 DM.v 中增加高位补零截取逻辑。
  3. Store 类（写内存）：
    • MemWrite = 1，RegWrite = 0（严禁写寄存器）
    • storeSel：00 为 sw，01 为 sh，10 为 sb。
    • DM.v 内部自动支持字节/半字写入。

条件传送型指令

  1. 典型指令：movz（rt 为 0 时存 rs 到 rd）、movn（rt 不为 0 时存 rs 到 rd）。
  2. Controller 配置：
    • RegDst = 1（写 rd）
    • ALUsrc = 0，MemWrite = 0，MemtoReg = 0
    • type：ALU 直通 inputA
    • 动态写使能：RegWrite = (movz && RD2 == 0) || (movn && RD2 != 0)

  4. 切片与掩码的选择
    切片[base +: width] 宽度是固定常数的时候用；
    掩码在提取长度是动态变量的时候用
    造掩码：
    1. 种子：A :32’b1(单点定位和借位减法) B : 32’hffffffff(整片裁剪)
    2. 造低位n个1:
      种子A左移n位，借位减1 low_mask = (32’b1 << N) - 1
    3. 造高位n个1：
      种子B左移 32 - n 位 high_mask = 32’hffffffff << (32 - N)
    4. [high : low]为1
      len = high - low + 1
      造出低len个1 (32’b1 << len - 1)
      将它整体左移low位 ((32’b1 << Len) - 1) << low
