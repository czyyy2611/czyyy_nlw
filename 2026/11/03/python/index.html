与C的区别

  1. 无需入口函数
  2. 使用严格缩进（4个空格），而不是{}
  3. 不需要分号，直接换行

输入输出与变量

变量

输出

print()默认自动换行，f-string，变量直接放进{}

输入

input()统一读取为字符串,需要数字运算时，显式调用类型转换函数 int() 或 float()
input().split() 按空格切分，map(int, …) 把切出来的每一项转为 int

流程控制

条件判断

省略小括号，结尾跟冒号，逻辑与或非直接用and or not
注意是elif

循环结构

range(start, end, step)左闭右开

用enumerate()获取下标

while循环条件不需要加括号

容器与数据结构

列表

变长动态数组（有点像vector），能存任意混合类型
a = [1, 2, 3, 4, 5]
b = list(range(5))
负索引：a[-1] # 5 最后一个
a[-2] # 4 倒数第二个
切片：左闭右开
a[2:6] a[:4] a[6:] a[::-1]

元组

可以理解为只读的列表

字典

原生内置高度优化的散列表，直接通过大括号 {key: value} 操作

函数

可返回多个值
