# 并查集
---
# 原理
1. 一开始每个元素都有自己的集合，这个集合只有自己这个元素
2. `int find(i)` 查找i所在的集合的代表元素
3. `bool isSameSet(a, b)` 判断a, b是否在同一个集合里
4. `void union(a, b)` 将a, b 所在的集合合并

# 代码实现
```cpp
vector<int> father;
vector<int> size;

void build();

int find(int i) {
    if (i != father[i]) {   
        father[i] = find(father[i]);    //递归 + 扁平化
    }
    return father[i];
}

bool isSameSet(int x, int y) {
    return find(x) == find(y);
}

void union(int x, int y) {
    int fx = find(x);
    int fy = find(y);
    if (fx != fy) { //小挂大优化
        if (size[fx] >= size[fy]) {
            father[fy] = fx;
            size[fx] += size[fy];
        }
        else {
            father[fx] = fy;
            size[fy] += size[fx];
        }
    }
}
```
