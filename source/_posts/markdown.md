# markdown
# 标题
- 语法：使用 **#** 创建1-6级标题
- **#** 号和标题文字之间必须有一个空格
- **#** 号必须在行首，前面不能有其他字符
---
# 文本格式
- ** xx ** 表示 粗体 **xx**
- \* xx * 表示 斜体 *xx*
- \*** xx *** 表示 斜粗体 ***xxx***
- \~~ xxxxxx \~~ 表示 删除线 ~~xxxxxx~~
- 三个以上的星号、减号、底线来建立一个分隔线
---
# 列表
1. 无序列表
   - 使用 * 、 + 或是 - 作为列表标记（建议使用 - ）
2. 有序列表
   - 数字 + .
3. 任务列表
    \- [ ] 未完成的任务
    \- [x] 已完成的任务
   - [ ] 未完成的任务
   - [x] 已完成的任务
---
# 引用块
1. 单级引用
   - 段落开头使用 > 符号 ，然后后面紧跟一个空格
>这是一段引用
2. 多级引用
\>最外层
\>>第一层嵌套
\>>>...
>最外层
>>第一层嵌套
>>>...
---
# 代码
1. 行内代码 使用 \` 包起来 \`printf\` 
   `printf`
2. 区块代码 使用\```包裹
    \```
    这是一段代码
    \```
    ```
    这是一段代码
    ```
3. 语言表示 语法高亮 高级特性

# 链接
1. \[链接名称](链接地址)
\[链接文字](链接地址 "可选的标题")
[链接名称](链接地址)
[链接文字](链接地址 "可选的标题")
2. <链接地址>
3. 锚点链接 ： 
   1. \[第一章：介绍](#第一章介绍)
    [第一章：介绍](#第一章介绍)
    2. 锚点规则：
标题会自动生成锚点
锚点名称通常是标题的小写形式
空格替换为连字符
移除特殊字符

    3. 手动创建锚点：
   \<a id="custom-anchor"></a>
    \## 自定义锚点位置
    \[跳转到自定义位置](\#custom-anchor)
    4. 页面顶部返回链接：
    \[回到顶部](#)
---
# 图片
1. \![替代文字]\(图片路径)
\![替代文字]\(图片路径 "图片标题")
其中图片路径可以是相对路径，也可以是绝对路径；
2. 图片尺寸控制
   1. 使用HTML img 标签
   \<img src="image.jpg" alt="描述文字" width="300" height="200">
   \<img src="image.jpg" alt="描述文字" width="50%">
    \<img src="image.jpg" alt="描述文字" style="width: 300px; height: auto;">
    2. 图片对齐
   \<!-- 居中对齐 -->
\<div align="center">
  \<img src="image.jpg" alt="居中图片" width="400">
\</div>
    \<!-- 左对齐（默认） -->
\<img src="image.jpg" alt="左对齐图片" style="float: left; margin-right: 20px;">
    \<!-- 右对齐 -->
\<img src="image.jpg" alt="右对齐图片" style="float: right; margin-left: 20px;">
